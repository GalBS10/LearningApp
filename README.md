# Effective Java App — Setup Guide

## Why this isn't a single "download and run" folder

The files provided (App.tsx, src/, package.json, tsconfig.json, etc.) are the
**JavaScript/TypeScript layer** of the app. React Native also needs native
`ios/` and `android/` folders (Xcode project, Gradle project) that must be
generated by React Native's own CLI — they can't be hand-written or copied
safely. So step 1 below generates those, then you drop these files in on top.

## Prerequisites (Windows, since that's your setup)

1. **Node.js** 18+ — https://nodejs.org
2. **Java Development Kit (JDK) 17** — required for Android builds
3. **Android Studio** — installs the Android SDK, emulator, and platform tools
   - During setup, install: Android SDK, Android SDK Platform, Android
     Virtual Device
   - Set the `ANDROID_HOME` environment variable to your SDK path (Android
     Studio's SDK Manager shows this path)
4. **iOS builds are not possible on Windows** — you'll need a Mac (or a CI
   service like Expo EAS or Codemagic) for iOS. Android-only is fine for now.

Full official environment setup (worth following exactly once, since PATH
issues are the most common source of setup failures):
https://reactnative.dev/docs/set-up-your-environment

## Step-by-step

### 1. Generate the native project shell

```powershell
npx react-native@latest init EffectiveJavaApp --directory effective-java-app
cd effective-java-app
```

This creates the `ios/` and `android/` folders plus a default `App.tsx`,
`package.json`, etc. — you're about to overwrite the JS/TS parts.

### 2. Replace the generated files with the provided ones

Copy these files into `effective-java-app/`, overwriting what's there:
- `App.tsx`
- `package.json`
- `tsconfig.json`
- `babel.config.js`
- `metro.config.js`
- `index.js`
- `app.json`

Copy the entire `src/` folder into `effective-java-app/src/`.

### 3. Install dependencies

```powershell
npm install
```

### 4. Set up an Android emulator

Open Android Studio → More Actions → Virtual Device Manager → create a
device (e.g. Pixel 7, API 34) if you don't have one yet. Start it.

### 5. Run the app

```powershell
npx react-native start
```

In a **second** terminal, with the emulator running:

```powershell
npx react-native run-android
```

First build takes a few minutes (Gradle downloading dependencies). The app
should launch in the emulator showing the lesson feed.

  lesson feed with a default 10 min/day goal.

## If something breaks

- `npx react-native doctor` — checks your environment for common
  misconfigurations (PATH, SDK versions, etc.) and is usually the fastest way
  to diagnose a broken setup.
- Metro bundler acting stale after file changes: stop it and run
  `npx react-native start --reset-cache`.
